# UI/UX GUIDELINES: THE "PREMIUM" STANDARD

## 1. DESIGN PHILOSOPHY
- **High-End & Scalable**: The UI must compete with global leaders like MarketMan or Restaurant365.
- **Simplicity**: Optimized for local Kenyan staff. Large buttons, minimal typing, and high contrast for kitchen environments.

## 2. KEY VIEWS & HARDWARE
- **Kitchen/Barista**: Designed specifically for an 11-inch Android tablet. Large touch-targets, one-tap requisition requests, clear visual status.
- **Storekeeper**: Designed for an All-In-One Desktop Computer. High-density dashboards, weight-entry receive screens, connected to POS thermal printers and standard A4 printers for reporting.
- **Manager/Owner**: A mobile-friendly PWA dashboard showing the "Debt Forecast", "Supplier Balances", and "Usage Variance".

## 3. CONSTRAINTS
- **Cultural Sensitivity**: Use Barista/Café iconography; exclude any liquor/alcohol-related symbols or categories.
