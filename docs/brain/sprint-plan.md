# 5-DAY MVP SPRINT PLAN

- **Day 1: Foundation & Data**: Setup `unix-store-service` scaffold and MariaDB `unix_` schema for inventory and suppliers. Establish read-only connection to legacy POS tables.
- **Day 2: Procurement & Debt**: Build Supplier Ledger, Payment Scheduling logic (daily debt alerts), dynamic balances, and Order messaging (SMS/WhatsApp integration).
- **Day 3: Internal Flow**: Implement the Requisition workflow (11-inch Android Tablet for Kitchen <-> Desktop for Store).
- **Day 4: The Audit Engine**: Develop the Yield Configuration UI (staff-driven approximation) and the "Usage Variance" dashboard (Sales vs. Issues) including Staff Meal tracking. Implement focused High-Value Cycle Counting flow.
- **Day 5: Refinement & Demo**: End-to-end testing, Cloudflare Tunnel configuration, and MVP presentation.
